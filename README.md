# VetOS ERP Suite — Veterinary Hospital & Clinic Management

Comprehensive, role-based ERP management system built for **VetCare Specialty Pet Hospital** featuring:
- **Doctor Consultation & OPD Practice**: Live waiting queue, diagnosis, digital prescriptions, and manual consultation fees.
- **Front-Desk Triage & Intake**: Real-time client & patient registration with 10-digit Indian mobile validation and direct OPD dispatch.
- **Pharmacy, Retail POS & Inventory**: Batch tracking with FEFO automated dispatch and stock valuation.
- **Laboratory & Diagnostics**: Test booking, requisition tracking, and automated clinical reports.
- **Pet Boarding & Swimming**: Kennel occupancy, stay tracking, and hydrotherapy pool sessions.
- **Double-Entry Accounting & Finance**: General ledger, accounts receivable/payable aging, operating expense vouchers, and GST compliance.

## Local Development

```sh
npm install
npm run dev
```

## Production Build
